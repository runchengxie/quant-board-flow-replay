# 使用与口径

[English](usage.md)

选择交易日、板块分类和窗口。初始游标位于第一分钟，初始板块按代码确定，不挑收盘赢家。
选定板块后，移动游标和改变窗口不会自动换成新的排名第一。

仅看到游标模式隐藏后续数据，纵轴仅按已显示数值计算；全日概览须显式选择。
两种方式都不证明当时的信息可得性：分钟曲线是盘后归档，可能包含供应商修订。
名单采集时间单独显示，不能把同日名单自动认定为开盘前已知。

排名是两个准确端点的累计主力净流入之差，区间内每个点均须存在，且不能跨午休。
缺值不作零、不插值。原值单位为元，两种语言均按亿元展示，时间统一为Asia/Shanghai。

页面将全天分钟点覆盖与当前可比较窗口分开。缺少当日名单时只显示代码，应有板块范围未知，
不以后来总目录代替。覆盖点数不能证明历史成分或板块互不重叠，板块流入不能直接加总。
来源区分交易日、归档快照时间、分钟记录归档时间与名单采集时间。

当前页面展示盘后分钟曲线，真实盘中快照是另一份资产，继续留在数据平台归档中。
构建或打开页面都不补缺口、不请求供应商、不更新任何生产别名。

“流入最多”只列正的窗口增量，从大到小排列；“流出最多”只列负增量，
从最负的值开始排列。各取前12名，同值按代码排序。零值不进入任何一边。
紧凑窗口也保留双向榜。单独的有符号榜仍按增量降序排列，包含零值与负值。

## 固定观察名单研究

查看某日数据之前，先在源码目录之外的带日期笔记中写下板块身份
（`type` 和 `code`）、上海时区的固定观察时刻、研究问题及排除规则，保留原稿。
将这些身份加入观察名单；缺失时保留缺失，不事后换成当天表现最强的板块。
浏览器保存的偏好可随时修改，只为操作方便，不能证明名单曾提前锁定。

盘后归档完成后，选择交易日，依次移到预先约定的游标时刻，保持名单不变，
点击“导出观察记录 JSON”。每份记录保留名单顺序、当日名称、5/15/30分钟
全部增量、以 `null` 表示的缺失值、归档清单标识及可用的采集来源信息。
开盘初段、内部缺点和跨午休的窗口仍记为不可用。这些是截至游标的向后回看
资金流差值，不是未来收益。导出采用稳定机器字段、亿元单位和上海本地时刻。

将下载文件、原始计划和简短的带日期解释保存在项目的外部数据目录下。
记录缺点、名单采集时刻、偏离原计划之处及其他可能解释。跨日比较时保持
板块身份、时刻和窗口一致；修改名单时应在下次使用前留下版本记录。
可以先问：同一板块在三个回看窗口内，资金增量呈持续还是反转？
不要看到结果后再挑案例。

导出是事后研究记录（`pointInTime: false`），不提供不可篡改的事前承诺，
也不计算收益。盘后归档曲线和名单不能证明盘中信号何时真实可用、策略是否
盈利，或真实信号是否验收通过。这些问题需要另行开展时点采集、预先约定检验，
并使用独立的价格和执行数据。导出成功或榜单有数据不代表获得了研究结论。
