# 板块资金流回放

[English](README.md)

从经过校验的归档生成离线页面，按交易日查看板块主力净流入，以及5、15、30分钟的增量。
页面不连接供应商，不需要数据库服务，也不加载外部资源。

采集、归档与权威质量仍由数据平台负责，本项目负责展示。**盘后取得的分钟曲线不代表当时已经
可获得的信息**，隐藏后续点也不能据此做严格的盘中信号回测。板块成分存在重叠，不能加总为全市场资金流。

## 生成本地页面

需要Python 3.12以上及uv。设置已有归档路径，以及位于项目源码之外的全新输出目录：

```sh
uv sync --locked --no-dev
uv run --locked --no-dev board-flow-replay build --archive "$BOARD_FLOW_ARCHIVE" --out "$REPLAY_OUTPUT"
```

用浏览器打开`$REPLAY_OUTPUT/index.html`，保留其同目录文件。支持直接打开本地文件，无需启动服务器。
默认英文，可显式切换中文；浏览器允许存储时会记住语言和选中板块。

构建器兼容`board-flow-parquet-v1`及不含producer信息的旧归档，核对hash、结构、行数和主键。
缺失保留为缺失，缺当天名单会提示，不用后来名单补历史名称。原归档和SQLite始终不写。
已有输出拒绝覆盖，入口最后发布；中断产生的新目录保留供检查，不自动覆盖重试。

详见[使用与口径](docs/usage.zh-CN.md)、[归档契约](docs/archive-contract.zh-CN.md)及
[开发验证](docs/development.zh-CN.md)。真实数据、生成页面和截图不进入仓库，测试与CI仅用合成数据。

点击“紧凑小窗”可使用窄窗口布局，查找板块后点击“关注选中板块”，最多固定观察 12 个板块。列表同时显示回放时点的 5／15／30 分钟增量，不完整窗口显示 —。浏览器允许存储时会记住观察列表和布局；名称只取选中日的名单，当日无数据的板块保留代码。本版是离线归档小部件，会醒目标出最新归档交易日，不监测实时采集，也不自动刷新。
